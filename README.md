## 📱 Phone Stock Management (C++)

This is a simple C++ console application that manages phone stock for three brands: Apple, Samsung, and Huawei.

The program allows the user to:
- Select a phone brand using a single character input (`A`, `S`, or `H`)
- View how many additional phones can be added to the selected brand (maximum stock per brand is 25)
- Add a valid quantity of phones to the chosen brand
- Display the updated stock for all brands at the end

### Key Concepts Used
- Pointers (`int*`) to directly modify stock values
- Input validation to prevent invalid updates
- `toupper()` for case-insensitive input handling
- Conditional logic with `if / else`

### Initial Stock
- Apple: 1  
- Samsung: 1  
- Huawei: 2  

### Constraints
- Maximum stock per brand: 25
- Negative values or values exceeding the limit are rejected

### Purpose
This project is a basic learning example focused on:
- Understanding pointers
- Managing simple state
- Handling user input safely in C++

Straightforward and focused on core C++ fundamentals.
